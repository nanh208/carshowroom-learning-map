Khởi chạy trên Windows

Chạy từ thư mục gốc CarShowroom. Backend phục vụ API và frontend mở giao diện.

Backend · cổng 8080

Cần JDK 21, Maven và SQL Server theo cấu hình dự án. Nếu dùng tệp .env.mssql, đoạn PowerShell dưới đây nạp biến vào tiến trình Maven.

Get-Content -LiteralPath '.env.mssql' | ForEach-Object {
  if ($_ -match '^(MSSQL_[A-Z0-9_]+)=(.*)$') {
    [Environment]::SetEnvironmentVariable($Matches[1], $Matches[2], 'Process')
  }
}
Set-Location backend
mvn spring-boot:run

Nếu máy dùng Maven đi kèm NetBeans, thay mvn bằng đường dẫn mvn.cmd tương ứng. Trong phiên chạy trước, RUN_BACKEND.bat báo lỗi cú pháp, còn chạy trực tiếp đã mở được Báo ARES.

Frontend · cổng 5173

Mở một PowerShell khác từ thư mục gốc, cài phụ thuộc nếu đây là lần đầu, rồi chạy Vite.

Set-Location frontend
npm ci
npm run dev

Cửa hàng · Quản trị · Báo ARES · Biên tập báo

Kiểm tra bản build với npm run build. Kiểm thử backend với mvn test từ backend. Profile kiểm thử dùng H2. Cấu hình chạy chính hiện dùng SQL Server, dù phần mở đầu README còn nhắc H2/MySQL.

Danh mục tra cứu

Tìm theo tên tính năng, route, API hoặc tên tệp. Mở “API và tệp liên quan” để truy vết từ giao diện.

Tính năng / điểm vàoCách dùng và logicVị trí trong mã
Phạm vi là mã nguồn hiện tại của dự án gốc. Các đường API là kiểm kê tĩnh từ khai báo Spring, các tệp liên quan lấy từ import trực tiếp và lời gọi API nhận diện được. API ghép động hoặc qua tiện ích trung gian cần tra tiếp trong tệp nguồn. Sự xuất hiện trong bảng không đồng nghĩa đã kiểm thử từng màn hình hoặc bật từng tích hợp.
